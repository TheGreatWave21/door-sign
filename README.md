# Door Sign control page

Control page for a Bluetooth LE door status sign (ESP32 "Cheap Yellow Display").
Open https://thegreatwave21.github.io/door-sign/ in the **Bluefy** browser on iPhone
(Safari has no Web Bluetooth), tap Connect, and pick a status.

The page contains no secrets: the sign only accepts commands from phones bonded to it with a
passkey shown on its own screen.
